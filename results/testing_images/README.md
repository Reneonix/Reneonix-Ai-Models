# results/testing_images

Drop any image(s) here you want run through every trained model - source input for
`Scripts/images/image_predict.py` and `image_predict_sahi.py`. Accepts `.jpg .jpeg .png .bmp
.webp`. Not versioned/tracked data - just a scratch input folder, safe to add/remove images
freely.

Output lands in `../predicted_images/<expNNN>/` - see that folder's own README.

# Core dependencies for the waste identification project.
#
# IMPORTANT - torch/torchvision:
# Do NOT just `pip install -r requirements.txt` for these two. The plain PyPI
# builds are CPU-only and will silently replace a working CUDA install (this
# has happened before in this project - see README). Install them first, from
# PyTorch's own CUDA index, matching your GPU/driver (this project uses an
# RTX 5080, which needs the cu128 build):
#
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
#
# Then install everything else normally:
#
#   pip install -r requirements.txt
#
# If you ever `pip install --upgrade ultralytics` later, it can pull a plain
# CPU torch/torchvision again as a dependency - re-run the command above if so.
